# Phase 5a — Schema Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the six new Prisma models (AgentTemplate, AgentInstance, Skill, ConnectorInstance, AgentConnectorBinding, AgentAction) and five new enums (AgentInstanceStatus, ConnectorType, SenderRole, BindingDirection, AgentActionStatus) from spec §4, plus an optional `connectorInstanceId` FK on Conversation — without touching application code. The live Telegram bot must keep working exactly as before through every commit on this plan.

**Architecture:** Schema-only phase. No application code reads or writes the new tables yet. Each task adds one cohesive schema unit, runs `pnpm exec prisma format`, regenerates the Prisma client, pushes to the local Docker Postgres on `:5436`, verifies `pnpm typecheck` + `pnpm lint` stay green, and commits. Phase 5h handles the `TelegramLink` cutover; **this plan touches no existing models destructively** (only the additive `connectorInstanceId?` on Conversation in Task 8).

**Tech Stack:** Prisma 7 (`prisma-client` generator with `@prisma/adapter-pg`), PostgreSQL 18 on host port 5436 (docker-compose), pnpm 10 workspaces with Turborepo, Vitest 4 for the CRUD smoke tests in Task 9.

**Builds on:** `main` HEAD `5a6793d` (spec at `docs/superpowers/specs/2026-05-20-qolmeia-multi-agent-architecture-design.md`).

- [ ] **Step 1: Insert AgentInstance after ConnectorInstance**

Append after the closing `}` of `ConnectorInstance`:

```prisma
model AgentInstance {
  id              String                  @id @default(cuid())
  orgId           String
  templateSlug    String
  displayName     String
  mission         String                  @db.Text
  // null = use template default skill set; [] = explicit empty (no skills enabled).
  // Stored as Json? to preserve the null/[] distinction (Prisma scalar lists
  // can't be nullable in Postgres).
  enabledSkillIds Json?
  budgetCents     Int                     @default(0)
  status          AgentInstanceStatus     @default(ACTIVE)
  org             Organization            @relation(fields: [orgId], references: [id], onDelete: Cascade)
  template        AgentTemplate           @relation(fields: [templateSlug], references: [slug])
  bindings        AgentConnectorBinding[]
  actions         AgentAction[]
  createdAt       DateTime                @default(now())
  updatedAt       DateTime                @updatedAt

  @@unique([orgId, templateSlug])
  @@index([orgId])
}
```

**Why `enabledSkillIds Json?`:** Per spec §15, `null` means "use template default" and `[]` means "explicit empty". Prisma scalar list fields on Postgres are `NOT NULL DEFAULT '{}'` and cannot be nullable; using `Json?` preserves the spec's exact semantics. Phase 5b parses it via Zod when first read.

import { afterAll, beforeAll, describe, expect, it } from "vitest";

import { prisma } from "../client";

// These tests hit the live local Postgres (docker-compose, host port 5436).
// They assume `pnpm db:push` has been run. Each test creates its own scoped
// fixtures with unique-by-test prefixes so the suite can run repeatedly
// without an explicit truncate.

const PREFIX = `p5a-${Date.now()}`;
const tag = (key: string): string => `${PREFIX}-${key}`;

describe("Phase 5a schema", () => {
  // We rely on test ordering only for the cascade-delete final assertion;
  // every other test is self-contained.

  beforeAll(async () => {
    // Sanity: the new models exist on the typed Prisma client.
    expect(prisma.agentTemplate).toBeDefined();
    expect(prisma.skill).toBeDefined();
    expect(prisma.connectorInstance).toBeDefined();
    expect(prisma.agentInstance).toBeDefined();
    expect(prisma.agentConnectorBinding).toBeDefined();
    expect(prisma.agentAction).toBeDefined();
  });

  afterAll(async () => {
    // Best-effort cleanup of anything we inserted under our prefix.
    await prisma.agentAction.deleteMany({
      where: { agentInstance: { org: { slug: { startsWith: PREFIX } } } },
    });
    await prisma.agentConnectorBinding.deleteMany({
      where: { agentInstance: { org: { slug: { startsWith: PREFIX } } } },
    });
    await prisma.agentInstance.deleteMany({ where: { org: { slug: { startsWith: PREFIX } } } });
    await prisma.connectorInstance.deleteMany({ where: { org: { slug: { startsWith: PREFIX } } } });
    await prisma.organization.deleteMany({ where: { slug: { startsWith: PREFIX } } });
    await prisma.skill.deleteMany({ where: { id: { startsWith: PREFIX } } });
    await prisma.agentTemplate.deleteMany({ where: { slug: { startsWith: PREFIX } } });
  });

  it("creates a Skill row", async () => {
    const skill = await prisma.skill.create({
      data: {
        id: tag("skill-1"),
        displayName: "Test Skill",
        description: "A skill used in Phase 5a CRUD tests.",
        parametersJsonSchema: { type: "object", properties: {} },
        requiresApprovalDefault: false,
        requiredConnectorTypes: [],
      },
    });
    expect(skill.id).toBe(tag("skill-1"));
    expect(skill.requiredConnectorTypes).toEqual([]);
  });

  it("creates an AgentTemplate row with the many-to-many skill relation", async () => {
    const skill = await prisma.skill.create({
      data: {
        id: tag("skill-2"),
        displayName: "Tag-2 Skill",
        description: "for template binding",
        parametersJsonSchema: { type: "object", properties: {} },
        requiredConnectorTypes: ["TELEGRAM"],
      },
    });
    const template = await prisma.agentTemplate.create({
      data: {
        slug: tag("tpl-1"),
        displayName: "Template 1",
        description: "Phase 5a CRUD",
        defaultSystemPrompt: "system",
        defaultMission: "mission",
        compatibleInboundConnectorTypes: ["TELEGRAM"],
        compatibleOutboundConnectorTypes: ["TELEGRAM", "WHATSAPP"],
        canDelegateTo: [],
        skills: { connect: [{ id: skill.id }] },
      },
      include: { skills: true },
    });
    expect(template.slug).toBe(tag("tpl-1"));
    expect(template.skills).toHaveLength(1);
    expect(template.skills[0]!.id).toBe(skill.id);
    expect(template.compatibleOutboundConnectorTypes).toEqual(["TELEGRAM", "WHATSAPP"]);
  });

  it("creates an Organization + ConnectorInstance + AgentInstance + Binding + Action chain", async () => {
    const template = await prisma.agentTemplate.create({
      data: {
        slug: tag("tpl-2"),
        displayName: "T2",
        description: "d",
        defaultSystemPrompt: "p",
        defaultMission: "m",
        compatibleInboundConnectorTypes: ["TELEGRAM"],
        compatibleOutboundConnectorTypes: ["TELEGRAM"],
        canDelegateTo: [],
      },
    });
    const skill = await prisma.skill.create({
      data: {
        id: tag("skill-3"),
        displayName: "S3",
        description: "d",
        parametersJsonSchema: {},
        requiredConnectorTypes: [],
      },
    });
    const org = await prisma.organization.create({
      data: { name: "Phase 5a org", slug: tag("org") },
    });
    const connector = await prisma.connectorInstance.create({
      data: {
        orgId: org.id,
        type: "TELEGRAM",
        displayName: "Phase 5a chat",
        config: { chatId: "test-chat" },
        capabilities: { inbound: true, outbound: true },
        senderRole: "OWNER",
      },
    });
    const agent = await prisma.agentInstance.create({
      data: {
        orgId: org.id,
        templateSlug: template.slug,
        displayName: "Phase 5a agent",
        mission: "test",
        budgetCents: 5000,
      },
    });
    const binding = await prisma.agentConnectorBinding.create({
      data: {
        agentInstanceId: agent.id,
        connectorInstanceId: connector.id,
        direction: "BOTH",
      },
    });
    const action = await prisma.agentAction.create({
      data: {
        agentInstanceId: agent.id,
        skillId: skill.id,
        proposedInput: { foo: "bar" },
        proposedSummary: "test summary",
      },
    });
    const child = await prisma.agentAction.create({
      data: {
        agentInstanceId: agent.id,
        skillId: skill.id,
